Game Backlog App

This application was developed as a full-stack mobile solution for the WGU D424 Software Engineering Capstone project. It provides a comprehensive dashboard for gamers to track their library progress across multiple platforms.

Key Features

  • Interactive Dashboard: Expandable cards for detailed game management.
  • Multi-Platform Support: Track games across Steam, PSN, XBOX, and more.
  • Real-Time Search: Instant filtering of your entire game collection.
  • Advanced Analytics: Summary reports featuring automated Completion Rate calculations.
  • Modern UI: A high-contrast dark theme optimized for readability and accessibility.
